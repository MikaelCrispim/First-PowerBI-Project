# Data Jobs Dashboard v2.0 | Power BI
Turning job market noise into strategic insights for data professionals.

## About the Project
Navigating the data job market can feel like a maze with information scattered everywhere. This dashboard (V2.0) is designed specifically for Job Seekers, Job Transitioners, and Job Swappers to cut through the clutter!

Using a real-world dataset of 2024 data science job postings—rich with details on titles, salaries, and locations—this project offers a streamlined, single-page interface to quickly explore crucial market trends and compensation insights.

---

## Skills Showcased
This project demonstrates an end-to-end Business Intelligence workflow:

- ⚙️ Power Query ETL: Data cleaning, shaping, and transformation of raw job posting data.

- 🔗 Data Modeling: Building efficient data models using Star Schema principles.

- 🧮 DAX Fundamentals: Creating measures and aggregations to derive key KPIs.

- 🎨 Dashboard Design & UI/UX: Crafting an intuitive, visually appealing, and user-centric report layout.

- 🖱️ Interactive Features: * Slicers: Enabling dynamic, user-driven data filtering.

     - Buttons & Bookmarks: For streamlined navigation and managing report views (including Drill-Through).

![Dashboard Version 2](/images/dashboard_v2.png)   

## Dashboard Overview
- The second iteration consolidates the report into a single, focused mission control, placing the most critical market insights at the user's fingertips.

- Key Performance Indicators (KPIs): Instant view of Job Count, Skills Per Job, Median Yearly Salary, and Median Hourly Salary.

- Skill Popularity: Analysis of top-demanded skills by job percentage or total count.

- Salary Benchmarking: Direct comparison of salaries across various job titles.

- Geospatial Insights: Interactive map charts to visualize global job distribution.

# Conclusion
Version 2.0 showcases Power BI's ability to transform extensive job posting data into a powerful, streamlined tool for career analysis. It empowers professionals to filter and explore essential market insights efficiently on a single page, helping them make data-driven decisions about their next career move.
